# Script: T1R5

> **ISP 1 — FibraNet GT** · AS 100 · OSPF área 0 · Router de acceso **Atención al Cliente**
> y punto de conexión del **servidor DNS/HTTP/HTTPS** de toda la topología.
> 🔴 La subred debe soportar **hasta 75 hosts** → **`/25` = 126 hosts útiles**.
> El segmento de servidores se movió a `192.168.48.48/30` porque las dos `/25`
> consumen la totalidad de `172.16.18.0/24`.

```text
enable
configure terminal
hostname T1R5

! Enlace hacia T1R3
interface g0/0
 description Link to T1R3 - 192.168.48.28/30
 ip address 192.168.48.30 255.255.255.252
 no shutdown
 exit

! LAN Atencion al Cliente - 172.16.18.128/25 (126 hosts utiles, >= 75 requeridos)
interface g0/1
 description LAN Atencion al Cliente - 172.16.18.128/25
 ip address 172.16.18.129 255.255.255.128
 ip helper-address 172.16.28.130
 no shutdown
 exit

! Segmento de servidores DNS/HTTP/HTTPS
interface g0/2
 description Link to Server DNS/HTTP/HTTPS - 192.168.48.48/30
 ip address 192.168.48.49 255.255.255.252
 no shutdown
 exit

router ospf 1
 network 192.168.48.28 0.0.0.3 area 0
 network 192.168.48.48 0.0.0.3 area 0
 network 172.16.18.128 0.0.0.127 area 0
 exit
```

## ACL aplicada en este router

```text
! ATC_IN -> aplicada en g0/1 in (ver ../ACLs/ACL_ATENCION_CLIENTE.md)
interface g0/1
 ip access-group ATC_IN in
 exit
```
