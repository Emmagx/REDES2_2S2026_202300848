# Script: T1R4

> **ISP 1 — FibraNet GT** · AS 100 · OSPF área 0 · Router de acceso **Administración**.
> 🔴 **Cambio del enunciado oficial:** la subred debe soportar **hasta 75 hosts**.
> `/26` (62 hosts) **no cumple** → se usa **`/25` = 126 hosts útiles**.

```text
enable
configure terminal
hostname T1R4

! Enlace hacia T1R2
interface g0/0
 description Link to T1R2 - 192.168.48.24/30
 ip address 192.168.48.26 255.255.255.252
 no shutdown
 exit

! LAN Administracion - 172.16.18.0/25 (126 hosts utiles, >= 75 requeridos)
interface g0/1
 description LAN Administracion - 172.16.18.0/25
 ip address 172.16.18.1 255.255.255.128
 ip helper-address 172.16.28.130
 no shutdown
 exit

router ospf 1
 network 192.168.48.24 0.0.0.3 area 0
 network 172.16.18.0 0.0.0.127 area 0
 exit
```

## ACL

**Sin ACL (decisión de diseño).** La regla de Administración es *"habla y escucha a todos los
departamentos"*, así que su interfaz LAN se deja libre y las restricciones se aplican en el origen de
los departamentos que sí las necesitan. La restricción "nadie entra a Seguridad" se resuelve en el
destino con `SEC_OUT` en `CF-R3`. Ver [`../ACLs/ACL_ADMINISTRACION.md`](../ACLs/ACL_ADMINISTRACION.md).
