# Script: T1R1

> **ISP 1 — FibraNet GT** · AS 100 · OSPF área 0 · Router núcleo del árbol.
> Los enlaces punto a punto viven en `192.168.48.0/16` (bloque que el enunciado asigna para
> conectar routers y switches de capa 3), de modo que los 256 hosts de `172.16.18.0/24`
> quedan disponibles para las dos subredes `/25` de departamento (126 hosts útiles ≥ 75 requeridos).

```text
enable
configure terminal
hostname T1R1

! Enlace hacia el switch multicapa de borde BGP
interface g0/0
 description Link to SW-BGP-FG - 192.168.48.32/30
 ip address 192.168.48.33 255.255.255.252
 no shutdown
 exit

! Enlace hacia T1R2
interface g0/1
 description Link to T1R2 - 192.168.48.16/30
 ip address 192.168.48.17 255.255.255.252
 no shutdown
 exit

! Enlace hacia T1R3
interface g0/2
 description Link to T1R3 - 192.168.48.20/30
 ip address 192.168.48.21 255.255.255.252
 no shutdown
 exit

router ospf 1
 network 192.168.48.16 0.0.0.3 area 0
 network 192.168.48.20 0.0.0.3 area 0
 network 192.168.48.32 0.0.0.3 area 0
 exit
```
